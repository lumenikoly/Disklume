# Безопасность и границы гарантий

## Инварианты приложения

Файловую систему изменяет только подтверждённый план. Перетаскивание, Delete и добавление в план ничего не удаляют. Команда исполняется только для существующей записи текущей сессии. План имеет собственную ревизию. Архивирования и безвозвратного удаления нет.

Перед переносом проверяются идентичность корня и файла, обычный тип каждого компонента пути, отсутствие ссылок/точек перенаправления, размер и временные метки. Unix-проверка также учитывает время изменения метаданных. Отсутствие надёжного ID или даты делает запись недоступной для операции. Запись с изменившимися данными нужно пересканировать; старое подтверждение не используется заново.

Группы карты не равны списку разрешённых файлов. Удаляются только явно выбранные индивидуальные ID. Для Windows дополнительно отключены связанные операции над одноимённой папкой ресурсов HTML, чтобы системная оболочка не включила невыбранные файлы.

## Корзина

На Windows используется IFileOperation с FOFX_RECYCLEONDELETE, FOFX_EARLYFAILURE, FOF_NO_CONNECTED_ELEMENTS и проверкой GetAnyOperationsAborted. Нет ветви с FOF_ALLOWUNDO как единственным «обещанием» восстановления и нет вызова безвозвратного DeleteFile. Сетевые, специальные и неоднозначные verbatim-пути отклоняются. Преобразование Windows-путей выполняется через dunce, а не удалением префикса строки вручную.

На Linux используется gio::File::trash. В многопоточном процессе с GTK/WebKit не используется Linux-реализация trash-rs с известным ограничением потокобезопасности при перечислении точек монтирования. На macOS используется системный адаптер библиотеки trash. Ошибки не подменяются remove_file или remove_dir_all.

Проверка нативного поведения на реальных ОС обязательна перед выпуском. Выполненные сборки и проверки, включая их платформенный охват, перечислены в [отчёте о проверках](VERIFICATION.md); наличие проверки на одной ОС не является доказательством поведения на другой.

## Чего проверка путей не гарантирует

Системные API Корзины принимают путь. Между последней проверкой и использованием пути остаётся очень короткое окно подмены другим процессом — гонка TOCTOU. Проверка каждого компонента уменьшает риск случайной ошибки, но **не делает операцию атомарной и не защищает от вредоносного процесса с теми же правами**. Не следует использовать уборщик на дереве каталогов, которое параллельно изменяется недоверенным процессом.

Файловая система также может иметь общие блоки, снимки, сжатие и ссылки за пределами выбранной папки. Ни сумма размеров, ни перемещение в Корзину не гарантируют освобождения такого же объёма диска. Корзина может очищаться внешними средствами ОС — ClearMap не управляет сроком хранения в ней.

## Сбои

Если журнал недоступен, перенос не начинается. Намерение синхронно записывается перед действием. После ошибки записи результата очередь останавливается. При аварийном завершении запись «намерение» без результата не доказывает, был ли перенос выполнен: нужно проверить Корзину и исходную папку.

Журнал — диагностический след, не транзакция файловой системы, не резервная копия и не механизм восстановления. Планы не возобновляются автоматически. Уже завершённые действия после отмены остаются завершёнными.

Сбой системного API в редком случае может произойти после фактического перемещения. Тогда интерфейс показывает ошибку, а повторная проверка не найдёт исходный файл. Не пытайтесь «исправлять» это автоматическим удалением по другому пути.

## Открытие файлов

Открытие передаёт выбранный файл зарегистрированному системному обработчику, а не безопасному встроенному просмотрщику. Для известных исполняемых расширений и Unix executable-bit есть дополнительный диалог, но это не антивирус. Документ с активным содержимым также может быть опасен. Не открывайте недоверенные файлы только ради просмотра в приложении.

## Приватность

Нет HTTP-клиента, телеметрии, загрузки содержимого, CDN или внешних шрифтов. CSP ограничивает интерфейс локальными ресурсами и IPC. В разработке локальный сервер слушает только 127.0.0.1. Рабочая сборка сервера не содержит.

Журнал сохраняет полные пути в личном каталоге данных приложения. Его содержимое может раскрывать имена документов. Удаляйте его вручную при закрытом приложении, когда он больше не нужен.

При выборе сетевой или облачной папки сама файловая система может обращаться к сети. При запуске файла его системный обработчик также действует самостоятельно. «Нет сетевого клиента в ClearMap» не означает «запрещена сеть всем процессам ОС».
