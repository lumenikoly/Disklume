# Ручная проверка перед использованием реальных данных

Использовать отдельную временную папку с копиями, которые можно потерять. Никогда не брать Downloads или домашний каталог для первого испытания новой сборки.

## Сборка

Выполнить команды проверок из README. Зафиксировать ОС, архитектуру, версии Rust/Node/WebView, точный коммит и оба файла фиксации зависимостей. Проверить окно настоящего Tauri, а не только browser-пример. Для macOS отдельно проверить подпись и разрешения, для Linux — графический сеанс и GIO, для Windows — WebView2 и системную Корзину.

## Файлы и карта

Создать маленький текстовый файл, картинку, большой файл, пару точных копий, файл того же размера с другим содержимым и пустой файл. Добавить вложенную папку и имена с кириллицей, пробелами, кавычками, амперсандом. Сравнить число и размеры с файловым менеджером. Проверить все фильтры, пагинацию и раскрытие групп.

Проверить остановку большого сканирования, затем повторный запуск; интерфейс должен оставаться доступным. Оценить память и задержки на наборах 10 тысяч / 100 тысяч / миллион файлов отдельно. Измерить, а не предполагать результаты.

## Открытие

«Показать в папке» должно указывать на выбранный файл. «Открыть» должно передать тот же файл приложению по умолчанию. Для исполняемого файла отмена дополнительного диалога не должна запускать программу. У приложения не должно появляться административных прав.

## Корзина

Добавить два файла в план, отменить просмотр: оба должны остаться на месте. Убрать один из плана, подтвердить второй. Он должен исчезнуть из папки и появиться в настоящей системной Корзине с правильным исходным путём. Восстановить его через ОС и сравнить содержимое. Статистика не должна утверждать, что место уже освобождено.

Отдельно проверить невозможность использования Корзины, переполненную Корзину, файл больше допустимого для неё, файл с запретом изменения и отключённый внешний накопитель. Ни один сбой не должен приводить к предложению или выполнению безвозвратного удаления со стороны ClearMap. На Windows проверить HTML с соседней одноимённой папкой `_files`: невыбранная папка должна остаться на месте.

Во время очереди нажать «Остановить». Текущий системный вызов может завершиться; остальные пункты должны остаться. Попытка закрыть окно во время переноса должна быть отклонена с объяснением.

## Изменения и ссылки

После сканирования изменить выбранный файл, переименовать его и подменить родительскую папку ссылкой — отдельные прогоны. Старые ID не должны воздействовать на изменённый или подставленный объект. Пересканирование должно создавать новую сессию. На Unix проверить жёсткие ссылки и sparse-файл. На Windows — junction/reparse point и недоступную облачную заглушку.

## Сбой и приватность

Сделать журнал недоступным: перенос не должен начаться. В отдельном тесте принудительно завершить процесс между операциями и проверить понятность журнала; очередь не должна сама возобновиться после запуска.

Проверить отсутствие запросов приложения к внешней сети. Для этого использовать обычную локальную папку и не открывать файлы внешними программами. Демонстрационные данные не должны быть выданы за содержимое выбранной реальной папки.

## Папки

Сравнить суммы вложенных файлов в режимах «Файлы» и «Папки» для обеих метрик. Войти на несколько уровней, вернуться по пути и Alt+↑. Проверить пустые папки, каталог с более чем 200 элементами, поиск внутри текущей папки и пересчёт размеров предков после удаления файла. Ctrl+A выбирает только файлы показанной страницы, не содержимое вложенных папок.
